================================================================================
     ROBOTIC ARM — ROS 2 JAZZY + GAZEBO HARMONIC SIMULATION GUIDE
================================================================================

Environment: distrobox container `fusion-juno-gpu`
Stack: ROS 2 Jazzy, Gazebo Harmonic (gz sim), gz_ros2_control, ros_gz_sim

================================================================================
 1. ONE-TIME: INSTALL SIM DEPENDENCIES (inside distrobox)
================================================================================

  distrobox enter fusion-juno-gpu
  source /opt/ros/jazzy/setup.bash

  sudo apt update
  sudo apt install -y \
    ros-jazzy-ros-gz-sim \
    ros-jazzy-ros-gz-bridge \
    ros-jazzy-gz-ros2-control \
    ros-jazzy-controller-manager \
    ros-jazzy-joint-state-broadcaster \
    ros-jazzy-position-controllers \
    ros-jazzy-xacro \
    ros-jazzy-robot-state-publisher

================================================================================
 2. BUILD
================================================================================

  distrobox enter fusion-juno-gpu
  source /opt/ros/jazzy/setup.bash
  cd "/home/Beast/Documents/ROS2/HELLO WORLD"
  rm -rf build install log
  colcon build
  source install/setup.bash

  # REQUIRED: confirm new sim files are installed
  ls install/robotic_arm_control/share/robotic_arm_control/urdf/robotic_arm.urdf.xacro

  # Optional pre-flight check (writes debug log)
  bash scripts/verify_sim_setup.sh

================================================================================
 3. RUN SIMULATION
================================================================================

  ros2 launch robotic_arm_control simulation_launch.py

  Starts:
    - Gazebo Harmonic (world with table + objects)
    - Robot spawn via ros_gz_sim
    - ros2_control controllers (joint_state + arm + gripper)
    - /clock bridge
    - arm_controller node (after controllers load)

  Allow ~15 seconds for Gazebo and controllers to finish loading.

================================================================================
 4. SEND COMMANDS (second terminal)
================================================================================

  distrobox enter fusion-juno-gpu
  source /opt/ros/jazzy/setup.bash
  cd "/home/Beast/Documents/ROS2/HELLO WORLD"
  source install/setup.bash

  ros2 topic pub --once /arm_controller/commands std_msgs/msg/String \
    "{data: 'HOME'}"

  ros2 topic pub --once /arm_controller/commands std_msgs/msg/String \
    "{data: 'PICK 0.5 0.0 0.6'}"

  ros2 topic pub --once /arm_controller/commands std_msgs/msg/String \
    "{data: 'PLACE 0.6 -0.2 0.6'}"

================================================================================
 5. VERIFY
================================================================================

  ros2 control list_controllers
  # Expect: joint_state_broadcaster, arm_joint_position_controller,
  #         gripper_position_controller (all active)

  ros2 topic echo /joint_states
  ros2 topic echo /arm_controller/status

================================================================================
 6. RVIZ ONLY (no Gazebo)
================================================================================

  ros2 launch robotic_arm_control robot_launch.py

================================================================================
 KEY FILES
================================================================================

  urdf/robotic_arm.urdf.xacro   — robot + gz_ros2_control + Gazebo plugins
  config/ros2_control.yaml      — controller_manager config
  launch/simulation_launch.py     — full Harmonic simulation launch
  world/robotic_arm_world.sdf     — table + pick objects

================================================================================
